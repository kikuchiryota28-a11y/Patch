# Patch!

A viral social rewriting game for awkward everyday messages.

## Current architecture

- Next.js App Router
- TypeScript
- Tailwind CSS
- Supabase persistence
- AI auto-patches
- Notifications + Hall of Fame + Issue Gacha
- Infinite Re-Patch branching tree
- Patchsmith profiles + contribution heatmap + badges

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
